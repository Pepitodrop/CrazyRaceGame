# Code of Conduct

Crazy Race welcomes constructive participation from people of all backgrounds and experience levels.

## Expected behavior

- Be respectful, patient, and specific.
- Discuss ideas and code rather than attacking people.
- Give actionable feedback and accept corrections in good faith.
- Respect privacy and never publish another person's private information.
- Help keep issues and pull requests relevant to the project.

## Unacceptable behavior

Harassment, discriminatory language, threats, sexualized conduct, deliberate disruption, impersonation, doxxing, and repeated personal attacks are not permitted in project spaces.

## Enforcement

Repository maintainers may edit or remove comments, close or lock discussions, reject contributions, or restrict participation when behavior violates this policy. Enforcement decisions should be proportionate, documented where appropriate, and focused on protecting the community.

## Reporting

For conduct concerns, use a private GitHub report or contact the repository owner privately. Do not disclose sensitive personal details in a public issue.

This policy applies to repository issues, pull requests, discussions, reviews, and other project-controlled spaces.
