# Crazy Race 1.0.0

Crazy Race 1.0.0 is the first stable public release of the Dockerized 1v1 racing game powered by Rust, R, TrumpScript, and Piet.

## Highlights

- Play online through six-character room codes or use local pass-and-play on one device.
- Use the same responsive server-rendered interface on desktop, tablet, and mobile browsers.
- Race on a deterministic circuit generated by R at container startup.
- Hear announcements produced by the original pinned TrumpScript interpreter.
- Activate a boost value emitted by an executable Piet PPM program interpreted in Rust.
- Run the complete application in one hardened Docker container without a JavaScript application.

## Production and security work

- Non-root container user and read-only root filesystem.
- Dropped Linux capabilities and `no-new-privileges`.
- CPU, memory, PID, room-count, connection, request-size, and log limits.
- 256-bit bearer tokens sourced from the operating system random generator on Linux.
- Hidden move selections until both racers submit.
- Automatic cleanup of inactive rooms.
- Restrictive browser security and cache-control headers.
- End-to-end online and local gameplay tests against the hardened container configuration.

## Run locally

```bash
docker compose up --build
```

Then open `http://localhost:8080`.

## Production deployment

```bash
cp .env.example .env
docker compose -f compose.production.yml up -d --build
```

Terminate HTTPS at a reverse proxy. `deploy/Caddyfile.example` and `docs/PRODUCTION.md` provide a starting point.

## Important limitations

Crazy Race 1.0.0 is intended for a single application instance. Active rooms are stored in memory and disappear on restart. Horizontal scaling requires a shared transactional room store. Public deployments must use HTTPS because game URLs contain bearer tokens.

See the [full changelog](https://github.com/Pepitodrop/CrazyRaceGame/blob/v1.0.0/CHANGELOG.md), [production guide](https://github.com/Pepitodrop/CrazyRaceGame/blob/v1.0.0/docs/PRODUCTION.md), and [security policy](https://github.com/Pepitodrop/CrazyRaceGame/blob/v1.0.0/SECURITY.md).
